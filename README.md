# tara-privacy

The privacy policy for the Android app **طارة / Tara**
(`com.devcode.tara`), published as a page so Google Play can link to it.

**Live:** https://haithamtalalzz-netizen.github.io/tara-privacy/

This repository holds that one page and nothing else — no app source.

The same text is shown inside the app under
**الإعدادات ← المساعدة والدعم ← سياسة الخصوصية**. If one changes, the other
has to: Google reads the published page and the app's own text and compares
them against the Data safety declaration.

The source of truth is `docs/privacy.html` in the app repository; this is a
copy of it.
